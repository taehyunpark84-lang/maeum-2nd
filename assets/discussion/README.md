# 생각방 이미지 에셋

2026-11-23 제작. 제안 탭 이름은 **생각방**. 고민을 두고 세 가지 관점이 대화하는 기능의 이미지 준비 단계이며, 탭·팝업·토론 기능은 아직 구현하지 않았다.

후속 구현: 같은 날 생각방 UI·실제 AI 서버 연동·오프라인 시연 구현이 진행되었다. 아래의 미구현 표기는 이미지 제작 당시 기록이며, 최신 기능과 검증 상태는 `docs/THOUGHT_ROOM.md` 및 `docs/PROGRESS.md`를 따른다.

세 로봇은 같은 형태·표정·구도를 사용하고 몸체 색으로 구분한다. 배경은 실제 알파 투명도이며 이미지에 이름이나 고정 역할을 넣지 않았다. 색상은 화자 식별용이고, 현실성·미래성 같은 입장과 이름은 향후 고민 주제마다 별도로 할당한다.

이 폴더는 선정 원본을 보관한다. 앱에 사용할 동일한 복사본은 `mobile/assets/discussion/`에 있으며, `mobile/src/config/assets.ts`의 `discussionAssets`에 정적 `require`로 등록했다. 기존 이미지와 원본 생성 파일은 보존했다.

## 향후 화면 적용

- 배경은 세로 화면에 사용하고, 글자·버튼·말풍선은 React Native 컴포넌트로 올린다. 배경 이미지에는 UI가 들어 있지 않다.
- 프로필은 32~40dp, 역할 소개 팝업에서는 56~72dp 정도로 사용하되 얼굴과 안테나가 잘리지 않도록 contain으로 표시한다. 실제 기기에서 최종 크기와 여백을 확인해야 한다.
- 화자 구분에는 색상과 함께 주제별 이름·입장 텍스트를 표시한다. 색상만으로 역할을 전달하지 않는다.
- 본문 색은 기존 `#222922`, 패널은 기존 `#FFFCF7`와 조합하는 방향으로 제작했다. 화면 전체의 최종 글자 대비·가독성은 UI 구현 후 검증한다.

## 이번 범위와 다음 단계

이번에는 이미지 생성·저장·정적 참조 준비만 수행했다. 사용자 구상의 다음 동작은 미구현이다.

- 고민 입력 → 세 챗봇의 주제별 이름·입장 소개 → 확인 후 대화 시작.
- 서로의 발언에 공감·반대·질문으로 반응하는 대화, 중지·재개 및 한 턴 후 수동 이어하기.
- 사용자 발언과 중요하게 여기는 관점을 이후 대화에 반영.
- 재입장·앱 재시작 시 이전 기록 표시 설정, 기본값은 숨김.
- 진행 중 새 고민 입력으로 기존 주제를 종료하고 새 주제 시작.

새 페이지의 실제 AI 역할 배정·토론 생성·저장 구조는 후속 설계 및 구현 범위다.

## 생성과 검증 기록

내장 `image_gen.imagegen`으로 배경과 파란 로봇을 생성하고, 파란 로봇을 참조해 주황·보라 변형 및 파랑 투명 가장자리 정리본을 만들었다. CLI/API 직접 호출이나 앱 내 AI 키는 사용하지 않았다.

실제 사용한 전체 프롬프트는 `generation-prompts.json`, 파일 크기·알파 여부·생성 파일명·SHA256·앱 복사본 경로는 `manifest.json`에 기록했다. 선정 이미지는 도구가 출력한 PNG를 변형 없이 복사했다.

원본 시각 확인, PNG 디코딩, 캐릭터 RGBA 및 투명 픽셀 확인, 원본과 앱 복사본 SHA256 일치를 검사했다. 실제 앱 화면에서의 가독성·기기 표시는 아직 검증하지 않았다. 타입 검사·린트 결과는 `docs/PROGRESS.md`에 기록한다.
