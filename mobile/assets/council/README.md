# 마음 회의 캐릭터

- `character-reference.png`: 사용자가 제공한 `시작화면.png`를 바이트 변경 없이 복사. 각 캐릭터 영역(슬픔 x=31, 불안 x=235, 분노 x=438, 기쁨 x=642; y=148; 196×196)만 React Native Image와 overflow clipping으로 표시합니다. 시작 화면 전체를 UI로 사용하지 않으며 글자·입력창·버튼은 실제 컴포넌트입니다.
- `moderator-owl.png`: 내장 `image_gen.imagegen`으로 생성한 사회자 부엉이. 투명 RGBA, 1254×1254. 원래 생성 파일은 보존하고 앱 자산으로 복사했습니다.
- 실제 전체 생성 프롬프트·도구·PNG 규격·SHA256은 `manifest.json`에 기록했습니다.
- 기존 생각방 배경과 3인 로봇 자산은 변경하지 않았습니다.
