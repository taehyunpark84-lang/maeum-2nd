# maeum-2nd — 이후 클라우드 계획

> 2026-11-22 사용자 후속 요청으로 VM 배포, MySQL 전환, IP 기반 HTTPS 및 모바일 주소 변경을 완료했습니다. 현재 상태와 실행 명령은 [MAEUM_VM_RUNBOOK.md](MAEUM_VM_RUNBOOK.md)를 따릅니다. 아래는 최초 로컬 이전 당시의 계획입니다. 실제 AI 키 설정과 휴대폰 사용자 검증은 남아 있습니다.

이번 작업은 로컬 API·작업자·SQLite 실행 준비만 포함한다. Google Cloud 접속, 자원 생성, MySQL 접속 및 EAS build/update/submit은 수행하지 않는다.

1. 이후 요청에서 Google Cloud MySQL이 Cloud SQL인지 VM 설치형인지 확인한다. 새 전용 DB와 최소 권한 계정을 준비하며 원본 프로젝트의 DB/계정을 재사용하지 않는다.
2. API와 그림 작업자를 VM에서 별도 프로세스로 운영하고 재시작·관측 정책을 정한다. 두 프로세스는 동일한 DB와 동일한 영속 이미지 경로를 사용해야 한다.
3. 비밀 설정은 서버에서 관리한다. API 키와 DB 비밀번호를 앱, EXPO_PUBLIC 변수, Git에 넣지 않는다. HTTPS와 실제 API 주소를 정하고 모바일 설정을 갱신한다.
4. 원본 이미지·썸네일의 영속 저장, 접근 제어, 백업·복원·삭제 정책을 확인한다. 여러 호스트면 공유 저장소 또는 비공개 객체 저장소가 필요하다.
5. 빈 MySQL에서 Alembic 마이그레이션, 인덱스·문자셋·외래 키·트랜잭션, 작업 큐 잠금과 동시성 및 장애 복구를 검증한다.
6. SQLite 파일은 MySQL로 자동 이전되지 않는다. 그 시점의 로컬 데이터를 옮길지 먼저 결정하고, 필요하면 별도 이관 절차와 건수·관계·이미지 무결성 검증을 마련한다.

연결 정보나 키는 이번 단계에서 요청하지 않는다. 실제 AI 모델 접근·비용·품질, 개인정보·안전 대응은 운영 전 별도 검토한다.
