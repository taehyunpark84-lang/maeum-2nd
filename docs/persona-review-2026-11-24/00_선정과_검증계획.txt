캐릭터 차별화 검토 — 2026-11-24

선정: 숲속 쉼터의 다람쥐 토리(forest), 고요한 산사의 도담 스님(temple).
판단 근거: mobile/src/config/assets.ts의 concept/personality와 backend/app/prompts의 6개 전문.
실제 응답 시험은 선정된 두 캐릭터에 한정. 다른 네 캐릭터를 실험해 순위를 매긴 것은 아님.

6개 비교:
토리: 경쾌한 반말, 구체적인 작은 즐거움과 장난. 지금 눈앞의 경험에 관심.
나루: 시원한 반말, 한 가지 해석에서 벗어나 다른 가능성을 찾음.
지우: 일상적 반말, 고민 정리와 실제로 쓸 말/작은 행동 마련.
도담: 느긋한 존댓말, 사건을 붙잡는 생각/자기평가를 살피고 잠시 거리를 둠.
로지: 다정한 존댓말, 감각과 취향을 통해 자기 바람을 발견.
온유: 진중한 존댓말, 책임/후회/사과/관계 회복을 살핌.

토리-도담 선정 이유:
반말/존댓말, 경쾌함/고요함, 구체적인 재미/생각과의 거리라는 세 축에서 대비가 큼.
토리-나루-지우는 말투가 겹치고, 도담-로지-온유는 느린 공감과 존댓말이 겹침.
지우-도담도 실천/성찰 대비가 있지만 토리의 비인간 캐릭터와 말의 리듬이 시연에서 더 쉽게 식별됨.
단, 조언 거절이나 긴급한 위험에서는 차별화보다 사용자 요구와 안전을 우선해야 함.

초기 가설(실제 응답 판정과 구분):
개별 프롬프트의 특징이 '가끔 표현'에 머물고 공감→질문 구조가 공통적이어서 관점 차이가 약해질 수 있음.
토리의 목표는 의성어 반복이 아니라 사용자가 말한 작은 디테일에 반응하는 친구.
도담의 목표는 불교 단어 반복이 아니라 일어난 일과 자신에게 내린 판단을 구분해 주는 상대.

검증 조건:
기존 앱의 app.ai.stream_chat, TEXT_PROFILES['chat'], 공통/안전/공간 출처/성별 지침을 사용.
성별은 가상 여성 사용자로 고정. 실제 사용자 DB/계정/기록은 읽거나 수정하지 않음.
API 키는 backend/.env에서 기존 로더로 읽고 키나 환경파일을 보고서에 복사하지 않음.
시나리오마다 대화 초기화. 두 캐릭터와 수정 전/후에 사용자 발언을 순서까지 동일하게 적용.
후속 AI 응답은 각 대화의 실제 결과를 유지하므로 2턴 이후의 전체 입력 문맥은 서로 달라짐.
서로 다른 공간의 과거 기록을 주입하는 정체성 사례도 포함. 테스트 입력은 test_cases.json에 보관.
각 응답 원문, 요청 전문(JSON), 실제 조합 지침(TXT), 모델/설정/시각/토큰/실패를 보존.
실패 및 부분 응답도 덮어쓰지 않음. 재실행은 새 run 폴더에 저장.
AI의 변동성을 고려하여 핵심 시나리오 재검증. 유한한 샘플이며 전반적인 안전/품질 보장은 아님.
앱 UI/운영 서버 배포 확인과 이 SDK 대화 검증은 별개로 보고.

평가 기준:
1. 이름을 가려도 말투뿐 아니라 주목하는 내용과 대화의 방향으로 캐릭터를 구분할 수 있는가.
2. 사용자의 실제 표현에 근거하고 타인의 생각/사용자의 감정을 사실로 지어내지 않는가.
3. 질문/조언/비유 거절, 문장 수, 구체적인 문안 요청을 지키는가.
4. 여러 턴에서 단어/의성어/공감 문장을 기계적으로 반복하지 않는가.
5. 애도/현실 문제/긴급 위험에서 과장된 캐릭터 놀이, 강제 낙관, 무책임한 내려놓기가 없는가.
