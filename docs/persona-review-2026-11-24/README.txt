토리·도담 캐릭터 검토 기록

읽는 순서
00_선정과_검증계획.txt: 6개 캐릭터 비교와 두 캐릭터 선정 근거, 사전 평가 기준.
04_결과와_시연안내.txt: 최종 결론, 남은 문제, 시연 입력, 반영 범위, 재실행 방법.
01_발견문제와_대화원문.txt: 문제가 나타난 대화의 원문과 평가 메모.
02_프롬프트_수정이력_원문.txt: 수정 전부터 최종안까지 공통·개별 프롬프트 전문과 변경 diff.
03_수정전후_대화원문_비교.txt: 같은 사용자 입력에 대한 기존/최종 응답 전문.
05_전체_대화원문.txt: 중간안과 재실행을 포함한 모든 대화 원문.
06_실행정보와_검증.txt: 모델/설정/시각/호출 수/해시. verification.json은 기록 일치 검사 결과.
07_실행장애.txt: 모델 호출 전에 발생한 환경 장애 기록.

원본 폴더
before: 기존 프롬프트 원문, 실행 1차와 독립 재실행.
candidate_v1/v2/v3: 중간 수정안. 결과가 좋지 않아도 원문을 그대로 유지.
after: 최종 로컬 소스에 적용한 v4 프롬프트와 실제 실행.
각 버전의 prompts에는 TXT 원문. ai.py.txt/tuning.py.txt/chat_text.py.txt/mobile_concepts.ts.txt는 당시 코드/컨셉 자료.
각 run의 대화 TXT는 응답 원문. JSON에는 요청 지침과 문맥/응답/사용 토큰/시각 포함.
각 *_instructions.txt는 그 턴 모델에 실제 전달된 공통/안전/개별/공간 출처/성별 지침 전문.

기록의 사용자 발언은 평가용 가상 대화이며 실제 사용자 계정의 원문이 아니다. API 키는 포함하지 않는다.
수정 결과는 로컬 파일에 반영. 원격 배포/기기 설치는 이번 작업에 포함하지 않았다.
